# Results directory layout

This directory contains final reports, figures, tables, and workbooks produced
by Stage 3 and the full-scale map scripts. Reusable intermediate data is stored
under `PROCESSED/`, not here.

## Current result folders

```text
results/
├── 2025_results/                 Older evaluation using the latest 2025 NSTA snapshot
├── 2026_results/                 Older evaluation using the latest 2026 NSTA snapshot
├── joined_results/               Older evaluation using the joined NSTA facility union
├── new_eval_2026_results/        New ownership, anomaly, and annual NO₂ analyses
└── full_scale_maps/              Whole-area Sentinel map figures
```

`2026_results/` and `new_eval_2026_results/` are different analyses. The first
is the older numbered evaluation run against the 2026 NSTA dataset. The second
contains the newer facility ownership, anomaly, and annual trend work.

## Snapshot and joined evaluation folders

The folders `2025_results/`, `2026_results/`, and `joined_results/` share the
same layout:

```text
<dataset>_results/
├── FIRMS/                         FIRMS figures split by ownership category
├── rigs/<FACILITY>/               Per-facility outputs
├── output.xlsx                    Consolidated evaluation workbook
├── table_for_paper_no2.csv        NO₂ summary table
├── table_for_paper_viirs.csv      VIIRS/FIRMS summary table
├── SENTINEL_*.png                 Sentinel facility figures
├── FIRMS_S-NPP_data.png           FIRMS overview
├── emissions_*.png                Emissions summary figures
├── pie_*.png                      NSTA and ownership breakdowns
├── oil_rig_*.png                  Facility count and location figures
└── oil_price_simple.png           Oil-price comparison figure
```

- `2025_results/` uses the latest NSTA snapshot dated in 2025.
- `2026_results/` uses the latest NSTA snapshot dated in 2026.
- `joined_results/` uses the full mapped union, preferring the newest available
  facility attributes.

These folders are generated by the 2025 evaluation suite within Stage 3.

## New 2026 evaluation

```text
new_eval_2026_results/
├── source/                         Run-provenance copies of the NSTA mapping and manifest
├── yearly_facility_emissions/      Annual facility values and regional trend reports
├── anomaly_detection/              Monthly platform/FPSO anomaly analysis
├── eni_to_ithaca_energy/           Eni-to-Ithaca ownership comparison
├── shell_equinor_to_adura/         Shell/Equinor-to-Adura ownership comparison
├── archive/                         Retained historical source bundle
└── README.md                        Overview of the ownership comparisons
```

### `source/`

- `mapped_surface_points.csv` is the mapping snapshot copied into the result
  bundle for provenance.
- `mapped_surface_points_manifest.json` identifies and checksums the source
  NSTA snapshots used by the run.

The authoritative working copies remain under `PROCESSED/NSTA/`.

### `yearly_facility_emissions/`

- `facility_emissions_<YEAR>.csv` contains one row per applicable facility for
  that year, its observation-weighted annual NO₂ mean, coverage information,
  and change from the preceding year.
- `annual_summary.csv` contains one matched-cohort overall metric per year.
- `README_NORTH.md` reports trends and leading facility contributions for
  facilities at latitude 56° or above.
- `README_SOUTH.md` reports the equivalent analysis for facilities below 56°.

The 2026 values cover January through October and compare those same months in
2025. The CSV values are Sentinel-5P NO₂ column estimates in `mol/m²`, not
direct mass-emission totals.

### `anomaly_detection/`

```text
anomaly_detection/
├── northern_north_sea/
│   ├── anomalies_ranked.csv
│   ├── top_anomalies.md
│   └── plots/
├── southern_north_sea/
│   ├── anomalies_ranked.csv
│   ├── top_anomalies.md
│   └── plots/
├── excluded_facilities.csv
├── unscored_observations.csv
├── analysis_summary.json
└── README.md
```

The regional CSVs rank monthly deviations from each facility's usual seasonal
pattern. Read the local `README.md` before interpreting the scores because the
analysis is descriptive and does not establish causation.

### Ownership-comparison folders

Both `eni_to_ithaca_energy/` and `shell_equinor_to_adura/` contain:

- `data/`: yearly facility NO₂ CSVs grouped by ownership outcome.
- `figures/`: facility, group, and pre/post comparison figures.
- `highlighted_facilities.xlsx`: the NSTA mapping with relevant ownership rows
  highlighted.
- `README.md`: case definitions, exclusions, and interpretation notes.

## Full-scale maps

`full_scale_maps/` contains whole-area Sentinel figures:

- `map_<CHEMICAL>.png`: standard chemical map.
- `custom_map_<CHEMICAL>.png`: custom map with facility overlays or alternate
  styling.

These files are generated separately from Stage 3 by
`src/get_SENTINEL_maps.py` and `src/get_SENTINEL_maps_custom.py`.

## Legacy folders

- `old/` contains historical outputs retained for reference. Current pipeline
  stages do not use these files as inputs.
- `FIRMS/` at the root of `results/` contains figures from the earlier
  unscoped FIRMS workflow. Current dataset-specific FIRMS figures are written
  beneath `2025_results/`, `2026_results/`, and `joined_results/`.

Do not use legacy folders to replace missing `RAW/` or `PROCESSED/` inputs.
